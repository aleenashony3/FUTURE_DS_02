# FUTURE_DS_02
Professional Telco Customer Churn Dashboard built with Python, Pandas, and Plotly, analyzing churn, revenue exposure, payment methods, internet services, and customer lifetime.

Telco Customer Churn Dashboard

📌 Project Overview

This project analyzes customer churn in a telecommunications dataset and presents the results through an interactive dashboard built using Python, Pandas, and Plotly.

The dashboard focuses on customer retention, churn behavior, revenue exposure, payment methods, internet services, and customer lifetime.

🎯 Objectives:

Analyze customer churn percentage,
Calculate key business KPIs,
Identify churn patterns across payment methods,
Compare churn rates across internet services,
Analyze customer lifetime for retained and churned customers,
Estimate monthly revenue exposure from churned customers

📊 Dashboard KPIs:

Total Customers,
Average Tenure,
Monthly Revenue,
Churn Revenue Exposure

📈 Dashboard Analysis:

Customer Churn Percentage,
Churn Rate by Payment Method,
Churn Rate by Internet Service,
Customer Lifetime: Retained vs Churned

🛠️ Technologies Used:

Python,
Pandas,
Plotly,
Google Colab

📂 Dataset:

The project uses the Telco Customer Churn dataset containing customer demographics, subscription details, services, charges, tenure, and churn information.
